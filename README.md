### What This Shit Can Do

NovaBank includes customer registration and login, account dashboards, deposits, withdrawals, money transfers, beneficiary management, transaction history, transaction details, loan applications, loan repayment, notifications, profile management, and a separate admin side. May security page and account controls din para hindi basta basta nagiging fucking financial disaster ang buong system.

The project also handles banking operations with **PDO prepared statements, CSRF protection, password hashing, session protection, IDOR checks, login lockouts, security logs, admin authorization, database transactions, and row locking for money related operations**. Basically, sinubukan kong lagyan ng enough security checks para hindi maging “UPDATE balance SET money = money + 999999” simulator.

### Tech Stack

No Composer. No Node.js. No npm. Pure PHP chaos lang. Walang unnecessary framework at walang 900 dependencies para lang makapag transfer ng fake money.
