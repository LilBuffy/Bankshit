## 🛡️ Security

Includes:

* PDO prepared statements
* CSRF protection
* Password hashing
* Session protection
* IDOR checks
* Login lockouts
* Security logs
* Admin authorization
* Database transactions
* Row locking for money operations

Basically, I tried not to build a fucking disaster.
